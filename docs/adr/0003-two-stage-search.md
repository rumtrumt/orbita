# 3. Двухступенчатый смысловой поиск

**Контекст.** Поиск должен находить близкое по смыслу и честно отвечать «не нашла». Замер на
paraphrase-multilingual-MiniLM показал верный первый результат во всех случаях, но абсолютные
значения пересекаются: нужное совпадение «поездка» — 0,37, ложное «рецепт борща» — 0,46. Более
крупная multilingual-e5-large (2,2 ГБ) ранжирует так же, а разрыв между классами у неё 0,01–0,02.

**Решение.** Совпадение по леммам принимается сразу. Близость от 0,7 принимается как смысловая.
Средняя зона от 0,3 отправляется в LLM, которая отбирает подходящие записи. Без LLM средняя зона
принимается только от 0,53.

**Последствия.** Лёгкая модель на CPU и точные ответы. Цена: около секунды на запрос из средней зоны.
Без LLM полнота падает, но поиск не начинает выдавать мусор.
