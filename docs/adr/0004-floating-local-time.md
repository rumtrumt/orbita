# 4. Локальное время записей

**Контекст.** Если хранить встречу в UTC, смена часового пояса пользователя сдвинет «встречу в 10
утра», а серия повторений разъедется при переводе часов. Запись «в пятницу» вообще не имеет момента
времени.

**Решение.** Дата и время хранятся локально, раздельными полями, без часового пояса. В UTC хранится
только `remind_at`, момент срабатывания.

**Последствия.** Модель совпадает с тем, как думает человек, а запись без времени выражается
естественно. Цена: совместная встреча в разных поясах потребует отдельного поля с поясом.
